# rx 모듈 사양

`rx.py`에 `fullmatch(pattern: str, text: str) -> bool`을 구현한다. 패턴이 `text` **전체**와 일치하면 True, 아니면 False다.

## 문법

- 메타문자는 `. * + ? | ( ) [ ] { } \` 다. 그 밖의 문자는 자기 자신과 일치하는 리터럴이다.
- `\x`: 메타문자 `x`를 리터럴로 쓴다(`\.`, `\*`, `\\`, `\[` 등). 메타문자가 아닌 문자 앞의 `\`는 입력으로 주어지지 않는다.
- `.`: 임의의 문자 하나.
- `[abc]`, `[a-z0-9]`, `[^abc]`: 문자 클래스. 클래스 안에는 리터럴 문자와 `x-y` 범위만 온다. 맨 앞의 `^`는 부정이다. 클래스 안에 `]`, `\`, 부정 표시가 아닌 `^`, 범위 표시가 아닌 `-`는 입력으로 주어지지 않는다.
- `(...)`: 묶음. 비어 있을 수 있다(`()`).
- `A|B`: 선택. 빈 가지를 허용한다(`a|`, `(|b)`).
- 수량자는 바로 앞의 원자 하나(리터럴, `.`, 클래스, 묶음)에 붙는다: `*`, `+`, `?`, `{m}`, `{m,}`, `{m,n}` (0 ≤ m ≤ n ≤ 30).
- 수량자가 연달아 붙는 패턴(`a**`, `a+?`)은 입력으로 주어지지 않는다.
- 입력 패턴은 항상 위 문법에 맞는다. 텍스트 길이는 최대 1000이다. 텍스트에 개행 문자는 없다.

## 요구

1. 결과는 위 문법 범위에서 Python의 `re.fullmatch(pattern, text) is not None`과 같아야 한다.
2. `rx.py`는 `re`, `regex`, `fnmatch` 같은 정규식·패턴 라이브러리를 import하거나 호출하면 안 된다. `eval`/`exec`/동적 import도 금지다. 표준 라이브러리의 다른 모듈은 써도 된다. 직접 만든 테스트 코드에서 대조용으로 `re`를 쓰는 것은 괜찮다.
3. 최악의 경우에도 다항 시간이어야 한다. 예를 들어 아래 호출은 각각 1초 안에 끝나야 한다. 단순 백트래킹은 여기서 지수 시간이 걸린다.
   - `fullmatch("(a*)*b", "a" * 40)`
   - `fullmatch("(a|aa)+c", "a" * 40)`
   - `fullmatch("(a?){25}a{25}", "a" * 25)`
   - `fullmatch("(a*)*", "a" * 1000)`
