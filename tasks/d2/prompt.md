`python3 -m unittest discover -s tests`를 돌리면 `test_currency_switch`가 실패한다. 원인을 찾아 근본적으로 고쳐라.

- 같은 종류의 결함이 저장소의 다른 곳에도 있으면 함께 고쳐라. 숨은 테스트가 다른 인자 조합으로 확인한다.
- 캐시는 유지해야 한다. 같은 인자로 다시 부르면 `catalog`의 조회 함수가 다시 호출되면 안 된다.
- `catalog.py`와 기존 테스트 파일은 고치지 마라. 테스트 파일을 새로 추가하는 것은 괜찮다.

마지막에 원인, 고친 곳, 함께 찾은 다른 결함을 짧게 보고하라.
