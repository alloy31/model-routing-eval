이 디렉터리는 `shiplane`이라는 파이썬 서비스의 저장소다. 아래 질문의 답을 저장소에서 찾아라. 저장소 파일은 수정하지 마라.

질문
a. `config/staging.json`의 `http.retries` 값
b. `CircuitBreaker` 클래스가 정의된 파일의 저장소 기준 상대 경로
c. `retry` 데코레이터의 `base_delay` 기본값
d. `GET /healthz` 요청을 처리하는 함수의 이름
e. `shipments` 테이블의 컬럼 개수
f. `MAX_TIMEOUT` 상수의 값

마지막에 아래 형식의 JSON 코드블록 하나로 답하라.

```json
{"a": 0, "b": "path", "c": 0.0, "d": "name", "e": 0, "f": 0}
```
